Toutes les valeurs de inputmode

Touche chaque champ pour voir le clavier virtuel changer selon la valeur d'inputmode. Le comportement exact dépend du navigateur et de l'OS.

none

N'affiche aucun clavier virtuel du tout. Utile pour une saisie custom (ex. un pavé numérique fait maison), quand tu gères toi-même l'entrée.

inputmode="none"

text (valeur par défaut)

Clavier standard, alphanumérique complet, pour du texte libre.

inputmode="text"

numeric

Pavé numérique 0-9 pur, sans signe ni point. Idéal pour un code PIN, un CVV, un ID numérique.

inputmode="numeric"

decimal

Chiffres avec séparateur décimal, mais sans signe négatif. Pour des quantités, des prix positifs.

inputmode="decimal"

tel

Pavé téléphonique classique avec chiffres, #, * et +.

inputmode="tel"

email

Clavier texte avec raccourcis @ et . mis en avant.

inputmode="email"

url

Clavier texte avec raccourcis /, . et parfois .com mis en avant.

inputmode="url"

search

Clavier texte standard, mais la touche "Entrée" devient généralement "Rechercher" (ou une icône loupe).

inputmode="search"

Bonus : sur <textarea>

inputmode fonctionne aussi sur les zones de texte multi-lignes, pas seulement sur <input>.

<textarea inputmode="numeric">
À ne pas confondre avec l'attribut type (number, tel, email...), qui ajoute aussi une validation native. On combine souvent les deux, ex. type="text" inputmode="numeric" pour un code postal sans les flèches +/- du type number.
